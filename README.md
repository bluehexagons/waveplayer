# waveplayer

An old JavaScript-based waveform-displaying audio player I wrote for an internal website.

Includes a test page and some of my earlier attempts at songwriting.

## Testing

Visit [bluehexagons.github.io/waveplayer/](https://bluehexagons.github.io/waveplayer/) and load an audio file.

Click to seek, double-click to play. Space bar will toggle play/pause while the waveform is in focus.
